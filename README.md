# R Leren – Eerste Maand (LTA-HHS)

Deze repository bevat twee documenten voor nieuwe medewerkers van  
het Lectoraat Learning Technology & Analytics (De Haagse Hogeschool):

1. **01-installatie-handleiding.md**  
   Installatie van R, RStudio en (indien nodig) Rtools.

2. **02-cursus-eerste-maand.md**  
   Zelfstudieprogramma voor de eerste maand R (ongeveer 4 weken).

## Werkwijze

1. Volg eerst de installatiehandleiding volledig.
2. Maak vervolgens een eigen lokaal R-project aan.
3. Werk de wekelijkse opdrachten uit in eigen `.R` scripts.
4. Gebruik het maanddocument als leidraad tijdens de sparringmomenten.

> Deze repository bevat geen datasets en geen uitgewerkte oplossingen.  
> Alle oefeningen worden lokaal uitgevoerd binnen een eigen R-project.

## Doelgroep

Nieuwe medewerkers met data-analyse-ervaring (Excel/SPSS)  
zonder programmeerervaring.
